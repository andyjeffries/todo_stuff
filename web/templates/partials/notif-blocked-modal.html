Reminders are blocked

Your browser previously denied notification permission for this site. Browsers won't show the permission prompt again — you'll need to re-enable it in your settings, then reload this page.

Safari (macOS)
  1. Open Safari → Settings… (⌘ + ,).
  2. Click the Websites tab.
  3. Select Notifications in the left list.
  4. If this site isn't listed, the checkbox at the bottom — "Allow websites to ask for permission to send notifications" — is unchecked. Tick it, then reload this page and click "Enable reminders" again.
  5. Otherwise, find this site in the list and change it to Allow, then reload.

Web notifications also require Safari 16 or later on macOS Ventura+. On iPhone/iPad they only work when the page has been added to the Home Screen as a Web App.

Chrome / Edge / Brave
  1. Click the padlock (or "Not secure") icon next to the address bar.
  2. Choose Site settings.
  3. Under Notifications, pick Allow.
  4. Reload this page.
Firefox
  1. Click the padlock icon next to the address bar.
  2. Click the > next to "Permissions".
  3. Find Send Notifications and clear the "Blocked" override (or pick Allow).
  4. Reload this page.
