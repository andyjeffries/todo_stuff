How to set up an iPhone or iPad

Do this once on each device: accounts like this aren't shared through iCloud. Give each device its own app password.

1. Add the account

  1. Create an app password above, named after the device.
  2. Be on the home Wi-Fi, or switch the VPN on.
  3. Open Settings → Apps → Reminders → Reminders Accounts → Add Account → Other → Add CalDAV Account. (If the menus have moved, search Settings for "CalDAV".)
  4. Server {{.DAVServer}}, User Name {{.User.Email}}, Password the app password, Description TodoStuff. If the phone can't find that name (over the VPN, say), use the server's IP address instead.
  5. When it says it can't connect using SSL, choose to continue without SSL. It only asks once.
  6. If it won't verify: open the account's Advanced Settings, turn SSL off and set the port to {{.DAVPort}}.
  7. On the account's screen, switch Reminders on (Calendars can stay off).

2. Make it Siri's default list

  1. Open Settings → Apps → Reminders → Default List and choose Inbox under TodoStuff.
  2. Try it: "Hey Siri, remind me to test TodoStuff in two minutes". It should appear here within a minute.
  3. Siri can also use a project by name: "add milk to my Shopping list".

Good to know

  • The phone sends changes straight away. Changes made here reach it when you open Reminders, or on its fetch schedule (Settings → Apps → Calendar → Calendar Accounts → Fetch New Data).
  • Away from home without the VPN, changes wait on the phone and sync when it can reach this server again. Alarms still ring.
  • Moving a reminder to another list on the phone re-creates it as a new task here.
  • Lists are your projects: create, rename and delete them here, not on the phone. Completed reminders show for 30 days.
  • Lost a device? Revoke its app password above.
